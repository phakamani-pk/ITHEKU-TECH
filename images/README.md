# Images

Place the images you want used on the website in this folder, then tell us which
image should be used for each section. Descriptive filenames are helpful.

The source images in this folder are not committed. An optimized version of
the supplied dark logo is used for the site mark and favicon; the Vercel build
serves it as a static CDN asset. Founder photographs should be referenced from
a CDN rather than committed to the repository.
